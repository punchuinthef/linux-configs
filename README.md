# linux-configs
A collection of dotfiles and configurations for my Linux apps.

1. Hyprland Setup
Can be found at ~/.config/hypr/hyprland.lua. The 'modules' folder can be found at ~/.config/hypr/modules/.

Hyprland Setup also includes:
- HyprLock
- HyprIdle
- Hyprpaper


2. FastFetch Setup
Can be found at ~/.config/fastfetch


3. Cava Setup
Can be found at ~/.config/cava/

4. Fish Setup
Can be found at ~/.config/fish

5. sptlrx Setup 
Can be found at ~/.config/sptlrx

6. spotify-player Setup
Can be found at ~/.config/spotify-player
